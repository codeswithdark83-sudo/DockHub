DockHub

A personal bookmark and tools dashboard (startpage) in a single index.html file. No build step, no dependencies.

Features
Categories with editable titles and icons, bookmark cards with 3-dot edit/delete
Built-in logos for popular sites, custom logo upload
Global search that filters bookmarks and falls back to a web search
Dark/light theme, responsive layout with mobile bottom navigation
Demo email/password and Google-style sign-in (stored in the browser only)
Data is saved in the browser's localStorage
Run

Open index.html in a browser, or host it with GitHub Pages (Settings > Pages > Deploy from branch > main / root).

Notes
The admin dashboard and AI icon generator rely on the claude.ai artifact runtime and are unavailable when hosted elsewhere.
Sign-in is a demo and is not secure. Use a real backend (Firebase, Supabase) for production.
